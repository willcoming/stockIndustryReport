1. 一頁式懶人包

  • 台耀是原料藥、委託研發製造及注射劑平台，遵循 cGMP，服務學名藥、臨床／商業 API、ADC 相關與無菌針劑需求。
  • 位於製藥上中游：從 API 製程開發／量產延伸到小分子與大分子液體、凍晶注射劑；法規、品質和客戶驗證是核心門檻。
  • 2026H1 營收 21.75 億元、毛利率 40.97%、營益率 10.89%，但業外淨支出 2.12 億元使合併稅後淨損 0.38 億元；歸母淨利僅 0.043 億元、EPS 0.04 元。
  • 7 月營收年增 3.14%，前七月年減 7.23%；美國 Eribulin 注射劑上市與臨床 API 出貨是正面里程碑，尚未扭轉累計衰退。
  • 收盤 53.90 元、每股淨值 61.75 元，P/B 約 0.87 倍；成交 5,956 萬元剛越過門檻，雙策略買點但收盤位階僅 54.5%，需等續強。
  • 評級：觀察。資產折價與技術平台值得追蹤，但股東獲利、子公司與現金流證據不足。
  • 追蹤分部收入、營益率、業外／少數股權、FCF、利用率、查廠與量價。參照 TMO、Lonza、神隆、美時、保瑞、台新藥。

2. 公司如何賺錢

台耀從 API 製程開發、臨床樣品到商業量產取得產品與 CDMO 收入，並延伸注射劑研發、製造、授權與銷售。客戶在選定符合 cGMP 與法規要求的供應商後，重新驗證成本高，成功商轉專案可帶來多年收入。

API 與 CDMO 毛利受產品難度、批量、產能利用、原料、環安與專案階段影響；注射劑具有更高無菌與查廠門檻，也有研發及初期稼動成本。H1 本業獲利 2.37 億元，但業外後稅前僅 0.25 億元，且非控制權益虧損 0.42 億元，表示合併與股東獲利品質需仔細拆解。

3. 從公司反推產業

API／CDMO 讓藥廠外包製程開發、原料與製劑生產，降低固定投資並取得專業品質系統。需求來自專利到期、複雜學名藥、生技新藥管線、供應鏈多元化與無菌製造缺口。

產業處於成熟 API 與成長型高難度 CDMO／ADC／注射劑並存階段。長期驅動是外包率提升、高活性與複雜製程、在地化供應；短期波動是專案延後、客戶臨床失敗、查廠、批次良率、產能爬坡、原料與匯率。

5. 商業模式與護城河

  • 技術：製程化學、分析方法、高活性處理、無菌／凍晶及規模放大是核心。
  • 客戶黏著／轉換成本：已納入藥證的 API／製造場地更換需重新申報與驗證，轉換成本高。
  • 規模：多平台可承接不同階段，但新產能未滿載會拖累折舊。
  • 品牌／案績：FDA 與國際查廠、Eribulin 美國上市增添履歷；單一產品成功不等於整體平台滿載。
  • 法規／資本：cGMP、環安、高活性防護、無菌品質系統與資本支出形成門檻。
  • 替代：標準 API 易受印度／中國價格競爭，高難度與長期客戶專案較難替代。

11. 投資標的分層

  • 核心穩健型：尚未，因股東獲利與現金流不穩。
  • 成長型：API 延伸注射／ADC／CDMO 有成長選擇權，需商轉證明。
  • 景氣循環型：部分屬於，API 價格與產能利用有循環性。
  • 高風險高報酬型：新平台爬坡若成功可重評，若失敗會承擔折舊與研發成本。
  • 只適合觀察、不適合輕易買進：本期主要分類。

12. 產業風險與反方觀點

多方認為台耀的 API、ADC 相關與注射劑整合可提高客戶轉換成本，P/B 低於 1 倍提供反轉空間。反方指出 H1 毛利高卻幾乎沒有歸母 EPS，前七月營收仍衰退；CDMO 專案、臨床成敗、查廠、無菌品質、產能利用、原料、匯率、客戶集中及子公司資本投入都可能侵蝕回報。警訊是營益轉弱、業外續虧、存貨／應收升、FCF 長期負值與品質事件。

14. 結論

台耀是理解 API 向注射劑／高難度 CDMO 延伸的好入口，外包製造長期值得追蹤。P/B 折價反映股東獲利轉換不足；雙策略訊號尚未得到營收、FCF 與量價續強完全確認。最終評級為 觀察，優先研究分部商轉、業外／子公司、利用率、FCF 與法規品質。
