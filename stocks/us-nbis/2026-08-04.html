1. 一頁式懶人包

  • 一句話介紹：Nebius 建置 GPU、網路、儲存、雲端與推論軟體，讓企業租用全棧 AI 運算能力。
  • 主要產業／位置：AI 雲端、GPU 基礎設施與推論平台，中游 neo-cloud／AI factory 營運商。
  • 核心投資邏輯：Q1 雲端收入與 ARR 超高速增長、Meta 長約與 NVIDIA 背書提高需求可見度；但建廠與 GPU 採購極耗資，Q1 資本支出 24.729 億美元、融資與稀釋大，8 月 3 日股價又出現 21.3%振幅。
  • 目前投資評級：觀察。基本面值得長期追蹤，惟研究日技術風險、估值與 Q2 證據不足，不適合追價。
  • 主要風險：CapEx／電力／施工、GPU 供應、Meta 等客戶集中、價格競爭、可轉債／權證稀釋、資安與技術迭代。
  • 追蹤指標：AI cloud revenue／ARR、調整 EBITDA 率、上線 MW／利用率、CapEx／FCF、客戶集中、完全稀釋股數。
  • 同業參照：CRWV、ORCL、MSFT、AMZN、GOOGL、DOCN；台股緯穎、廣達、技嘉、台達電與中華電是硬體／機電／IDC 間接參照。

2. 公司如何賺錢

  • 核心 AI cloud 提供 GPU 運算、儲存、網路、訓練、推論、serverless AI 與模型部署；收入來自按用量、保留容量及多年專屬叢集合約。
  • Meta 合約下的各訂單為五年期，首批部署預計 2027 開始，含 GPU 容量、儲存與連接服務；「最高 270 億美元」不是當期已認列收入，仍取決於交付與訂單條款。
  • Eigen AI、Clarifai 與 Tavily 能把業務從純 GPU 租賃延伸至推論最佳化、agentic search 與 Token Factory，提高每 GPU 價值的策略需由毛利驗證。
  • 集團另有 Avride 與 TripleTen；Q1 集團收入 3.990 億中 AI cloud 3.897 億，核心占比已極高。
  • 成長來自新 GPU／資料中心容量、利用率、客戶長約與產品上移；而非傳統軟體的低資本席次增長，折舊與資本成本不可忽略。

3. 從公司反推產業

  • AI 雲端解決企業取得 GPU、低延遲網路、儲存與模型工具的困難，客戶無須自行建資料中心與整合整個軟硬體棧。
  • 需求來自基礎模型、企業生成式 AI、agent、推論、機器人與 physical AI；供給受電力、土地、變壓器、冷卻、GPU 與施工速度限制。
  • 產業處於高速成長與大規模建設期，但也可能形成供給週期：若需求或模型效率變化低於容量擴張，GPU 價格與利用率會下降。
  • 長期驅動是 AI 滲透、token 用量與算力密度；短期變數是 NVIDIA 產品週期、電力接入、利率、客戶 CapEx、hyperscaler 自建與價格競爭。

5. 商業模式與護城河

  • 全棧技術：自研雲端、網路、運維與推論最佳化可提升 GPU 吞吐量、降低 token 成本；需由客戶留存與 margin 驗證。
  • 稀缺資源：Q1 已簽約電力超過 3.5 GW，公司提高年底目標至逾 4 GW，且擁有資產占逾 75%；電力與土地是關鍵選擇權。
  • 客戶黏著／轉換成本：大規模訓練與推論叢集的資料、網路與工作流整合形成轉換成本，但 Meta 等大客戶仍有強議價力與自建能力。
  • 規模經濟：高利用率可攤提 GPU、建築、能源與網路；低利用率會反向放大折舊與利息。
  • 資本門檻：Q1 籌得約 63 億美元與期末約 93 億美元現金（公司口徑）支持擴張，亦帶來可轉債和權證稀釋。
  • 替代風險：AWS、Azure、Google Cloud、Oracle、CoreWeave 以及企業自建皆是替代；模型效率提高可能減少每工作負載算力需求。

6. 重要財務與營運指標

  • 收入／ARR：集團 Q1 3.990 億、+684%；AI cloud 3.897 億、+841%；3 月 ARR 19.2 億、年增 674%，但 ARR 只是 3 月雲端收入乘 12，不是 GAAP backlog。
  • 成本／毛利：成本收入比 26%，依官方數字推算毛利率約 74%；仍需分離 upfront／長約與容量成本。
  • 營益／調整 EBITDA：集團調整 EBITDA 1.295 億；AI cloud 調整 EBITDA margin 約 45%。總營運成本 5.270 億，其中 D&A 2.120 億，顯示資產密集。
  • 淨利品質：GAAP 持續營運淨利 6.212 億與調整淨損 1.003 億差異巨大，需檢視非營運／公允價值項目，P/E 不適用。
  • 現金流／CapEx：OCF +22.58 億、資產採購 -24.729 億，簡化差額約 -2.149 億；OCF 可能受客戶預付款驅動，不能視為成熟 FCF。
  • 融資／稀釋：3 月完成約 43 億可轉債、NVIDIA 20 億預付權證；3 月底流通 253,898,194 股，另須納入 21,065,936 權證與可轉債潛在股數。
  • 產能／集中：追蹤已簽電力、實際上線 MW、GPU 數、利用率與前五大客戶；公開即期完整分布需查證。

11. 投資標的分層

  • 核心穩健型：不屬於；商業與資本結構變化太快。
  • 成長型：主要分類，Q1 AI cloud 收入與 ARR 極高成長。
  • 景氣循環型：具備 GPU／資料中心供給週期，需求與容量錯配會放大波動。
  • 高風險高報酬型：明確屬於；長約與軟體上移有上行，建設／融資失誤也可重挫。
  • 只適合觀察、不適合輕易買進：研究日最適用，因技術硬排除與 Q2／估值缺口。

12. 產業風險與反方觀點

  • 反方認為 AI 算力供給將快速增加、模型效率提升壓低每 token 成本，neo-cloud 定價與利用率可能低於建設假設。
  • Meta 等大客戶集中提高議價與取消／延遲風險；270 億美元上限並非無條件保證收入。
  • 電力併網、土地、變壓器、冷卻、GPU 與工程施工任何一環延誤都會使資本閒置。
  • NVIDIA 同時是關鍵供應商與股東，生態支持是優勢也形成依賴；出口管制、資安與資料主權增加跨國風險。
  • 財報警訊：CapEx 快於容量／收入、D&A／利息急升、利用率下降、客戶預付款負債／集中增加、可轉債或股數大幅稀釋。

14. 結論

  • NBIS 是理解 AI factory、neo-cloud、電力資產與推論平台的好入口；產業值得長期追蹤，但不是輕資產 SaaS。
  • 最重要邏輯是 Meta 等需求與逾 4 GW 目標能否準時轉為高利用率、可持續 FCF；最大風險是資本密度、集中、施工與稀釋。
  • 即期完全稀釋估值與 Q2 未核實，不能確定市場是否已過度反映成長。
  • 最終投資評級：觀察。優先研究容量交付、利用率、預付款品質與全稀釋 EV；待極端波動消化後才評估是否回到分批布局。
