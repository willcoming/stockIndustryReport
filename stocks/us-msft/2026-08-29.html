2. 公司如何賺錢

Microsoft 以企業訂閱、按使用量雲端服務、軟體授權、廣告、交易分潤和硬體賺錢。FY2026 10-K 顯示，Server products and cloud services（含 Azure）營收 1,294.25 億美元，Microsoft 365 Commercial 營收 1,019.97 億美元，兩者合計約佔全年營收 69.7%，是主引擎。

其他 FY2026 產品營收包括 Xbox 217.90 億、LinkedIn 198.17 億、Windows and Devices 170.84 億、搜尋廣告 151.76 億、Microsoft 365 Consumer 91.75 億、Dynamics 90.06 億，以及企業與夥伴服務 82.60 億美元。企業協議把身分、安全、資料、辦公和 Azure 綁在同一採購關係，提高續約和交叉銷售潛力。

成長驅動是 Azure 工作負載與 AI 容量、Microsoft 365 Copilot／E5 提高單價、商業席次、Dynamics、GitHub、LinkedIn 及搜尋。訂閱使營收穩定度高，但 Azure 用量、廣告、招募、遊戲與企業 IT 預算仍有循環；AI 資料中心另形成高資本支出週期。客戶橫跨企業、政府、中小企業、開發者與消費者，單一客戶集中度低，但上游 AI 晶片、電力和大型模型夥伴的依賴上升。

**簡單說，這家公司賺錢的方式是……**先讓企業用 Azure 運算與管理資料，再透過 Microsoft 365、Copilot、GitHub、Dynamics 與安全產品擴大每位客戶的經常性支出，同時以 Windows、LinkedIn、廣告與 Xbox 分散收入。

3. 從公司反推產業

Microsoft 反映的是「公有雲＋企業軟體＋AI 平台」產業。它解決企業彈性取得運算、儲存、資料庫、網路、安全與模型的問題，並把 AI 嵌入開發、文件、會議、分析與客戶關係流程。

IaaS 與 SaaS 已進入規模成熟期，生成式 AI 與代理式應用仍處成長／導入期。長期動能來自企業上雲、資料現代化、資安、模型能力、Copilot 滲透與開發者生態；短期波動則來自 GPU／電力供應、CAPEX 到位時點、AI 推論成本、企業預算與監管。

產業三個最重要問題：

  1. Azure 與 Copilot 的增量收入，能否跑得比資料中心折舊與電力成本快？
  2. 企業會集中於少數閉源平台，還是以多雲、開源模型和自建架構壓低平台定價力？
  3. Commercial RPO 的高成長能否在可接受的期限內轉成收入、毛利和自由現金流？

投資含意：護城河強能支撐測得的估值溢價，但無法豁免巨額投資回報不及預期的風險。

這些是研究情境，不是公司財測或目標價。目前 28.61 倍 trailing P/E 約反映基準情境上緣，而 1.76% FCF Yield 又表示市場假設 CAPEX 很快就能轉為現金回報。

新手買入

不適合因「是好公司」就一次追價。新手應先學會區分營業利益、營運現金流與 CAPEX，並用下次財報檢查 AI 變現是否快於折舊。

不同成本持有者

  • 低成本：可以基本面追蹤為主，但不應因獲利就忽略 FCF Yield 偏低。
  • 現價附近：重點是下一季 Azure、Cloud 毛利與 FCF 能否支撐基準情境。
  • 大幅獲利：將部位風險、稅務與自身配置分開思考；本報告不提供個人化比例。
  • 套牢：不應只因成本高就攤平；先確認投資邏輯是否仍完整。

等候買點條件

等 FY2027 營運證明 Cloud 毛利止跌、FCF 增速回升，或等估值回落至基準情境中低端，讓基本面與價格其中至少一項提供更佳安全邊際。

評級上調訊號

  • Azure 恒定幣別成長維持約35%以上，且不只來自容量補庫。
  • Microsoft Cloud 毛利率止跌或回升。
  • FCF 增速重新接近營收增速。
  • Copilot 席次、ARPU 或獲客證據更透明。
  • 價格回落但三年基準情境沒有變差。

評級下調訊號

  • Commercial RPO 成長無法轉為 current RPO 與收入。
  • 現金 CAPEX 持續快於營運現金流增量。
  • Cloud 毛利率與 Azure 成長同時下降。
  • 重大資安、監管或 OpenAI 關係破壞平台價值。
  • 估值繼續擴張，但核心 EPS／FCF 增長放慢。

反方觀點

最強的空頭論點是：市場仍用高毛利 SaaS 公司的視角給 Microsoft 溢價，但公司已變成每年投入超過千億美元現金 CAPEX 的重資本 AI 基建營運者。FY2026 現金 PP&E 增約 80%，Cloud 毛利率 66%，簡化 FCF Yield 只有約 1.76%；若 RPO 包含較長期合約，而 Copilot 單位經濟未被揭露，則需求熱度可能無法在折舊進入損益前產生足夠現金回報。這會導致 EPS 降速與估值倍數收縮同時發生。

要推翻此反方觀點，不是只看 Azure 成長或 AI 新聞，而是要看 Cloud 毛利率止跌、RPO 加速轉收入，並且 FCF 增速重新追上營收。

14. 結論

結論項目 判斷
是否為產業好入口 是。Microsoft 同時連結 AI 晶片、雲端基建、模型、企業軟體與最終用戶。
產業是否值得長期追蹤 是。企業資料、工作流與運算正重新整合，但資本強度高於傳統 SaaS。
最重要投資邏輯 Microsoft 能否把企業分發、Azure、Copilot 與 RPO 轉成可持續的自由現金流。
最大風險 CAPEX 與折舊先於 AI 變現，造成毛利、FCF 和估值同時承壓。
估值是否已反映成長 大部分已反映。28.61x P/E 不是極端，但 11.49x P/S 與 1.76% FCF Yield 要求高成長和資本回報都兑現。
最終投資評級 觀察。相比「分批布局」，目前更應等待 FCF／Cloud 毛利驗證或估值提供更佳安全邊際。
優先研究之產業鏈環節 AI 晶片與伺服器供給、資料中心電力、Azure／模型平台競爭、Copilot 單位經濟。

給初學者的最後一句話：Microsoft 的業務很強，但今天買的不只是軟體，也是一個正大舉興建 AI 基礎設施的重資本平台。所以不只要問「Azure 有沒有長大」，還要問「長大後有沒有留下更多現金」；在答案更清楚前，觀察優於追價。
