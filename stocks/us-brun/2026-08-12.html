1. 一頁式懶人包

  • Boost Run 擁有／租賃 bare-metal GPU servers，部署於美國 colocation，透過自有平台、第三方 AI 平台與 brokers 出租算力。
  • Legacy Boost Run Q1 revenue 1,095.6 萬美元、年增約 165%；gross profit 937.7 萬、gross margin 85.6%；但 D&A 472 萬、colocation cost 467 萬、net loss 412 萬美元。
  • Q1 GPU CapEx 893.1 萬美元、年增 1,211%，顯示收入成長高度依賴資本；公司投資簡報所稱 ARR／contracted revenue 是前瞻／非 GAAP，不能當已認列收入。
  • SPAC 後截至 6/1 約 3,189.6 萬 Class A、2,953.3 萬 Class B；424B3 登記最多 5,873.9 萬 Class A 轉售，另有權證／earnout，稀釋與 float overhang 顯著。
  • 評級：觀察。高成長與 GPU demand 值得追蹤，但新上市、客戶／合約、資本強度、會計可比性與股本風險尚未成熟。

2. 公司如何賺錢

  • 自有平台直接租 GPU；第三方平台租用基礎設施；brokers 買入容量再售。租約包含特定 GPU 使用權與 power、internet、security、support。
  • 公司擁有 GPU，colocation 提供機房、電力、網路與實體安全；客戶 provisioning 後控制設備使用，因此收入具有租賃成分。
  • 成長來自 GPU 數、利用率、合約期限、價格與 enterprise AI；另以閒置 GPU 取得 blockchain rewards，增加數位資產與收入品質風險。

3. 從公司反推產業

  • GPU cloud 解決企業無法快速取得昂貴 GPU、機房與運維的問題，需求來自模型訓練、推論、科學計算與 agent。
  • 產業處於高速擴建期；長期驅動為 AI 工作負載，短期受 GPU 供給／折舊、電力、租價、利用率、利率與客戶 CapEx 影響。
  • 供給增加或模型效率提高可能壓低 rental rate；硬體技術迭代會縮短經濟壽命並增加殘值風險。

5. 商業模式與護城河

  • 快速採購／部署 GPU、跨多個美國機房、價格曲線經驗與 Infrastructure as Code 是潛在執行壁壘。
  • 長約可提高可見度，但客戶／broker 集中、取消／信用、GPU 代際與服務 SLA 會影響實際價值。
  • 真正護城河須由 cohort 留存、利用率、contracted revenue 轉 GAAP、現金毛利與 equipment return 證明；資本本身可被競爭者複製。

6. 重要財務與營運指標

  • Legacy Q1 revenue 1,095.6 萬、gross profit 937.7 萬、gross margin 85.6%，前期分別 414.0 萬、343.7 萬、83.0%。
  • Q1 SG&A 266 萬、D&A 472 萬、colocation lease cost 467 萬、net loss 412 萬美元；高 gross margin 不等於扣除折舊／機房後高營益。
  • GPU CapEx 893.1 萬美元，前期 68.1 萬；追蹤 CapEx/revenue、asset utilization、GPU age、lease liabilities、OCF/FCF。
  • 6/1 A/B 股合計約 6,142.9 萬，另有 private/public warrants、earnout 與 resale registration；須用 fully diluted EV。
  • 客戶集中、ARR 定義、contracted revenue cancellation、應收、cash、debt 與 post-SPAC pro forma 需查證。

14. 結論

BRUN 是理解小型 bare-metal GPU rental 與 SPAC 資本結構的研究入口。最重要邏輯是 contracted revenue 能否轉為高利用率、扣除折舊／機房後的正 FCF；最大風險是客戶、硬體週期與轉售／稀釋。估值資料尚不足，最終評級 觀察。
