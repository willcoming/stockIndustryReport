1. 一頁式懶人包

  • 公司一句話：晶心科技提供 AndesCore／AndeStar RISC-V 處理器核心及軟體工具鏈，向晶片設計客戶收取授權、權利金及維護服務收入。
  • 所屬主要產業：半導體矽智財（CPU IP）；位於晶片架構、CPU 核心授權與軟體生態的前端關鍵層。
  • 產業鏈位置：上游 EDA／工具與下游 ASIC、SoC 設計及晶圓製造之間的可重複授權 IP 供應商。
  • 核心投資邏輯：RISC-V、AI 客製晶片、車用與網通增加 CPU 核心採用機會；成功量產後的權利金才是驗證商業模式品質的核心。
  • 目前投資評級：觀察。
  • 主要理由：2026 上半年營收改善，但 Q1 仍虧損且 P/E 不適用；7/30 K 線訊號亦屬「不建議追高」，應等 Q2 損益、權利金與現金流驗證，而非只依題材或單月營收判斷。
  • 主要風險：高研發費用、客戶 tape-out／量產延遲、Arm 與其他 RISC-V 業者競爭、出口管制與收入認列集中。
  • 最重要追蹤指標：授權／權利金收入占比、量產 SoC 出貨、營業費用率、營業現金流、AI／車用專案進度及 Q2 虧損縮小幅度。
  • 代表性美股與台股同業：ARM、Synopsys、Cadence；力旺、智原、創意、世芯-KY、聯發科。

2. 公司如何賺錢

  • 授權收入：客戶在 SoC 設計階段取得 CPU 核心、指令延伸與開發工具授權，收入多依合約里程碑認列。2025 年報揭露授權收入約 9.654 億元、占營收約 65%。
  • 權利金：客戶晶片量產後依出貨或合約條件支付。2025 年報權利金約 2.823 億元、占約 19%，是收入可重複性的關鍵。
  • 維護與服務：2025 年報維護服務約 2.270 億元、占約 16%，用於客戶整合、工具與版本支援。
  • 毛利率高不等於淨利高：IP 的直接成本低，惟研發工程師、EDA、海外據點與銷售為固定性支出；Q1 毛利率約 99.9%，但費用高於營收而虧損。
  • 成長取決於授權案數與單價、客戶量產率、每顆權利金、AI／車用高階核心滲透。公司非製造業，較重要的是研發人效、專案交付與客戶量產，而非工廠產能利用率。

3. 從公司反推產業

  • CPU IP 讓客戶不必從零設計處理器，縮短上市時間並降低驗證風險；RISC-V 雖為開放 ISA，商用核心、驗證與工具鏈仍有付費價值。
  • 需求來自 AI 加速器控制核、車用 MCU／ADAS、資料中心、網通、儲存、IoT 與消費性 SoC。
  • 產業處於成長與商業化並行階段：授權至 tape-out、量產、權利金的轉換可能跨數季至數年。
  • 長期驅動力：客製運算、RISC-V 生態成熟、AI 專用晶片與車用功能安全需求。
  • 短期波動因素：大型授權驗收、客戶融資與量產時程、出口限制、研發費用及匯率。

5. 商業模式與護城河

  • 技術壁壘：處理器微架構、低功耗、向量運算、功能安全、驗證與工具鏈需長期投入。
  • 規模與客戶黏著：CPU 一旦整合至 SoC，軟體、驗證與認證帶來轉換成本；新專案仍可能轉用 Arm 或其他 RISC-V IP。
  • 生態優勢：編譯器、除錯、開發板、作業系統與第三方 IP 的完整度會直接影響採用率。
  • 商業模式優點：純 IP 不與客戶推出自有晶片競爭；2025 年報提及累計客戶 SoC 出貨超過 190 億顆，顯示已有落地基礎。
  • 主要限制：規模、品牌與開發者生態仍小於 Arm；高階核心投資可能令費用成長快於權利金。

6. 重要財務與營運指標

  • 營收成長率：2025 年營收約 14.782 億元；2026 H1 約 8.926 億元、年增 62.07%。須拆解授權、權利金及服務以判斷品質。
  • 毛利率／營益率：Q1 毛利率約 99.9%、營益率約 -62.2%；收入規模能否跨過固定研發費用門檻是損益轉折重點。
  • EPS：2025 EPS -8.20 元、2026 Q1 EPS -3.28 元；轉盈前 P/E 不適用。
  • 現金流：2025 年營業現金流約流入 3.099 億元，但投資及籌資項目波動大，FCF yield 與現金消耗趨勢需以 Q2 財報再查證。
  • 訂單／量產能見度：追蹤授權 backlog、tape-out、量產客戶與權利金；存貨與傳統產能利用率非核心指標。
  • 客戶集中度與市占：應以年報附註、合約資產與應收帳款變化交叉驗證，避免單一大案拉高單季收入的錯覺。

11. 投資標的分層

  • 核心穩健型：目前不屬於，盈餘及現金流尚未穩定。
  • 成長型：屬於，動能來自 RISC-V、AI、車用與客製運算。
  • 景氣循環型：部分屬於，客戶投片與半導體資本循環影響採用和量產。
  • 高風險高報酬型：屬於，固定研發成本使營運槓桿顯著。
  • 只適合觀察、不適合輕易買進：現階段最合適分類，等待獲利拐點與估值安全邊際同時出現。

12. 產業風險與反方觀點

  • 多頭看好開放 ISA 與 AI 客製晶片；反方認為開放並不保證單一供應商取得商業價值，Arm 與其他 RISC-V 業者仍有強大競爭。
  • 估值風險：虧損公司在題材熱時容易以遠期營收定價，量產延後會造成倍數收縮。
  • 技術替代：客戶自研、Arm、SiFive／MIPS 等其他核心與不同加速器架構。
  • 政策與地緣：出口管制、客戶所在地與匯率會改變成交、收款及供應鏈。
  • 財報警訊：授權增加但權利金不增、合約資產或應收惡化、費用增速高於營收、現金消耗擴大。

14. 結論

晶心科是理解 RISC-V 處理器 IP 的好入口，長期產業值得追蹤，最重要的驗證是授權案是否轉成可重複權利金。上半年營收反彈為正面事實，但 Q1 仍虧損、Q2 完整財報未出，且 7/30 K 線訊號不支持追價。最終評級為觀察；優先研究高階核心量產、AI／車用客戶、工具鏈生態及權利金轉換。本報告僅供研究教育與情境分析，不構成個人化投資建議或獲利保證。
