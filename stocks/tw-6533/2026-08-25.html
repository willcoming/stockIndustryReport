1. 一頁式懶人包

  • 公司一句話：晶心科提供 AndesCore／AndeStar RISC-V 處理器核心、工具鏈與 AI 加速 IP，收入來自授權、量產權利金與維護服務。
  • 產業／位置：半導體矽智財（CPU IP），位於晶片架構與 SoC 設計前端的關鍵層。
  • 核心邏輯：RISC-V、AI 客製晶片、車用與網通擴大 CPU IP 採用；真正的品質驗證是授權轉成可重複權利金。
  • 目前投資評級：觀察。
  • 主要理由：H1 營收成長且 Q2 單季虧損較 Q1 收斂，但 H1 營業虧損 3.070 億元、P/E 不適用；8/25 僅單一 LZEMA20 訊號，仍須等待轉盈與現金流證據。
  • 主要風險：高研發固定成本、tape-out／量產延遲、Arm 與其他 RISC-V 競爭、出口管制、收入里程碑集中。
  • 追蹤指標：授權／權利金占比、量產 SoC、營業費用率、營業現金流、AI／車用專案與損益兩平時程。
  • 代表同業：ARM、Synopsys、Cadence；力旺、智原、創意、世芯-KY、M31、聯發科。

2. 公司如何賺錢

  • 授權收入：客戶在 SoC 設計階段取得 CPU 核心、延伸指令與工具授權，依合約或里程碑認列。
  • 權利金：客戶晶片量產後依出貨／合約支付，是可重複收入品質的核心。
  • 維護與服務：工具、版本支援、客製與整合服務；直接成本低，但研發工程師、EDA 與全球支援費用高。
  • H1 毛利率約 99.87%，但營益率約 -34.39%，說明高毛利不等於獲利；收入規模仍不足以完全吸收費用。
  • 成長來自授權案數／單價、客戶量產率、每顆權利金、AI／車用高階核心採用，而不是工廠產能利用率。

3. 從公司反推產業

  • CPU IP 讓客戶免於從零設計處理器，縮短上市時間並降低驗證風險；開放 RISC-V ISA 不等於商用核心與工具免費。
  • 需求來自 AI 加速器控制核、車用 MCU／ADAS、資料中心、網通、儲存、IoT 與消費 SoC。
  • 產業處於成長與商業化並行階段，授權至 tape-out、量產與權利金通常跨數季至數年。
  • 長期驅動為客製運算、RISC-V 生態成熟、AI 專用晶片及車用功能安全；短期受大型驗收、客戶量產、出口限制與費用影響。

5. 商業模式與護城河

  • 微架構、低功耗、向量運算、功能安全、驗證與工具鏈需要長期研發。
  • CPU 整合後的軟體、驗證與認證提高轉換成本；新專案仍可轉向 Arm 或其他 RISC-V IP。
  • 2026-06 公司宣布客戶 SoC 累計出貨逾 200 億顆，證明既有落地規模；但累計顆數不等於當期權利金或獲利。
  • AX46MPV 提供 64 位多核與最高 2048-bit VLEN，對 AI／資料中心有技術選擇權；品牌與開發者生態仍小於 Arm。

11. 投資標的分層

  • 核心穩健型：目前不是，盈餘與現金流尚未穩定。
  • 成長型：是，動能來自 RISC-V、AI、車用與客製運算。
  • 景氣循環型：部分是，客戶投片與半導體循環影響量產。
  • 高風險高報酬型：是，固定研發成本使營運槓桿顯著。
  • 只適合觀察：現階段最合適，等待獲利拐點與安全邊際同時出現。

12. 產業風險與反方觀點

  • 開放 ISA 與 AI 客製晶片是多方論點；反方是開放不保證單一 IP 商取得價值，Arm 與其他 RISC-V 競爭仍強。
  • 虧損公司在題材熱時常以遠期營收定價，量產延後會造成倍數收縮。
  • 客戶自研、Arm、SiFive／MIPS 等替代；出口管制、客戶所在地與匯率也影響成交與收款。
  • 警訊為授權增加但權利金不增、合約資產／應收惡化、費用快於營收與現金消耗擴大。

14. 結論

晶心科是理解 RISC-V CPU IP 的好入口，產業值得長期追蹤；最重要的驗證不是累計出貨新聞，而是授權能否轉成可重複權利金並跨過費用門檻。H1 營收成長正面，但營業虧損仍達 3.070 億元、P/E 不適用，8/25 也僅屬等待確認名單。最終評級為觀察；優先研究高階核心量產、AI／車用客戶、工具鏈與權利金轉換。
